# Benchmark Mode

Execute frozen Prism Labs benchmarks.

Every claimed artifact must be written into the lane workspace with `workspace_write` and verified with `workspace_list` or `workspace_read`. Prose describing a file is not a deliverable.

Benchmarks may produce software, research, designs, media, or other reviewable artifacts. Inspect `.skills/` before starting. When a relevant skill exists, read its `SKILL.md` and any `BENCHMARK.md` extension, then follow both. A rendered media artifact requires the capability-specific verification receipt; source code alone does not prove it works.

A draft is not permission to spend money. Launching requires an approved immutable specification and lane matrix.
