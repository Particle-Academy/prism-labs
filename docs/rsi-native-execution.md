# Native RSI execution

RSI tests use the existing owner approval, exact GO and one-time paid-work chain. The test cap must equal its approved run cap; all allocations still count against the persistent $5 owner session. Lanes are shuffled and persisted with their complete frozen definition. Duplicate delivery cannot buy another call. Native workers resolve the approved owner; they do not provision or authenticate accounts.

`RsiLaneProfile::installedReference()` reports the installed Harness version/source reference and a SHA-256 over a sorted map of relative runtime paths and raw file hashes (`composer.json`, `src`, `config`, `database`, `resources`). This is a loaded-runtime fingerprint, not an archive checksum or a claim that declared provenance was independently audited. Approval also binds the loaded core runtime. Changed bytes, configuration, lane fields or work bindings invalidate execution.

The first supported native profile is PHP `particle-academy/prism-harness`, the loaded exact package/reference, mode `rsi-test`, no named agent, text inference, no tools/skills/subagents/media and no unattached fixtures. It enforces native call/step, admission-time and positive output bounds. Other declared profiles and bounds remain visible as unsupported and make zero provider calls; they are never rewritten to fit this executor. Trusted prices come from explicit `prism-harness.pricing`, never guessed from model labels. Missing/invalid prices refuse before inference. A native time budget checks admission; it is not a claim that an already in-flight provider request was interrupted at that deadline.

`NativeCostObserver` commits a durable worst-case reservation before the native provider call. It refuses execution inside an outer database transaction: a savepoint cannot guarantee that reservation survives rollback. Concurrent workers lock the same authority session and run allocation, count all pending maxima and settled charges, and enforce the persistent per-work call count. Native children retain the observer; the host binds the declared provider/model and root run. Completed known usage settles once by native call ID; conflicting settlement replays refuse. Failed/abandoned unknown work charges its maximum. Settlement can complete after expiry or revocation, while new calls cannot. Worker death leaves a pending reservation. No lease timer, cancellation or cleanup refunds possibly in-flight external spend. There is no automatic reconciliation/refund endpoint.

This accounting controls admission using trusted bounds. Provider-reported billing, failures, retries and external behavior are not an invoice guarantee. Unjudged results record native run ID, output hash/byte count and missing instrument results as null. Artifact content capture defaults off; Harness still stores its normal private conversation. Provider outages are environment outcomes; unknown native errors are not package findings. This path cannot schedule a scorer, narrator or reviewer and cannot use their paid-work purposes.

The run-room PR must add complete frozen-contract review, instruments and evidence/cost display before public RSI creation. This change adds no public draft-creation UI and performs no operational database cutover.

Tests use isolated SQLite state and synthetic providers. The standalone PostgreSQL control runs only against CI's own service: it creates a random database, proves it differs from Lab/Sandbox/workspace defaults, runs the actual production observer with independent native workers, and drops that same database in `finally`. The forced-SQLite PHPUnit configuration remains in place. Local refusal tests perform no PostgreSQL connection.
